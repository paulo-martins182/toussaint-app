# Toussaint / 006

Landing autoral de lançamento para portfólio, construída para explorar atmosfera, scroll storytelling e frontend de alta performance.

## Stack

- Astro 7
- Tailwind CSS 4
- Three.js
- TypeScript

## Desenvolvimento

```bash
npm install
npm run dev
```

O projeto usa saída estática. A cena orbital é um módulo separado carregado sob demanda, com fallback de CSS e suporte a `prefers-reduced-motion`.
